# AI Customer Support Agent — LLM Evaluation Framework

A Python-based evaluation framework for assessing the quality,
reliability, and consistency of an LLM-powered customer support agent.

## Project Objectives

- Build a simple LLM-powered customer support agent.
- Evaluate response relevance, factual accuracy, and policy adherence.
- Detect hallucinations and unsupported factual claims.
- Integrate Verdict evaluations with Pytest.
- Perform regression testing across different agent configurations.
- Generate evaluation reports.

## Technology Stack

- Python 3.12
- OpenAI API
- Verdict
- Pytest
- GitHub Actions

## Project Status

Phase 1: Initial project setup and customer support agent development.

## Project Structure

- `agent/`: Customer support agent implementation.
- `config/`: Application configuration.
- `data/`: Business policies and evaluation datasets.
- `tests/`: Automated tests.
